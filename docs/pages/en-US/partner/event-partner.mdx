# Education Partner

<Callout type="info">
  **Event Sponsorship Policy Update — September 17, 2026:** Sponsorship is
  limited to events that are free to attend, are not conducted for profit, and
  do not provide event-related compensation or revenue to speakers or
  organizers. The revised policy applies to all new applications and
  applications pending review. Existing Partner status and previously approved
  Event Codes are not affected.
</Callout>

The Education Partner Program supports eligible **open-source, community, and educational events** organized by instructors, community leaders, hackathon organizers, and educational institutions. Approval as a Partner permits an organization or individual to submit eligible events for sponsorship through the Event Code program.

## Sponsorship Eligibility

An event must satisfy all of the following requirements to be eligible for sponsorship:

- The event is not conducted for profit.
- No attendance or participation fee is charged.
- Neither speakers nor organizers receive event-related compensation or revenue.

Zeabur evaluates each application on the basis of the information submitted and reserves sole and final discretion to approve or reject sponsorship.

## How It Works

<Steps>

### Submit a Partner Application

Submit an application through the [Partner Portal](https://partner.zeabur.com/apply). Partner applications are reviewed within 1–3 business days.

### Submit an Event Sponsorship Application

After receiving Partner approval, sign in to the Partner Portal and submit the required information for an eligible event.

### Application Review

Zeabur reviews event sponsorship applications within 1–3 business days. If an application is approved, the Event Code will be made available for distribution to attendees.

</Steps>

<Callout type="warning">
  First-time applicants must submit both the Partner application and the event
  sponsorship application at least five business days before the scheduled event
  date to allow sufficient time for review.
</Callout>

## Event Code Mechanism

An Event Code is a unique redemption code issued for an approved event. Upon redemption, the associated credits are added to the attendee's Zeabur account balance and may be applied to any paid Zeabur service.

- Each Event Code is issued for a specific event and remains valid only for the specified validity period, which typically ends at the close of the event date.
- Attendees may redeem an Event Code by using the event registration link (`https://zeabur.com/events?code=...`). Redemption occurs automatically upon registration. Alternatively, an attendee may enter the code on the Billing page after signing in.
- For complete redemption instructions, refer to [Redeem an Event Code](/partner/event-partner/redeem-event-code).

<Callout type="info">
  Redemption of an Event Code does not generate a commission under the Referral
  Program. Sponsored credits do not constitute a customer payment. A referral
  commission is calculated only after a user successfully completes a qualifying
  payment.
</Callout>

### Credit Amount

Each approved Event Code currently grants **US$10 in Zeabur account credit per attendee**.

The credit is added to the attendee's account balance and may be used for deployments, servers, AI Hub, and other paid Zeabur services. The number of attendees covered by sponsorship is determined separately for each event during application review.

### Eligible Use Cases

- **Free programming courses** — Students use Zeabur to deploy course projects.
- **Free technical workshops** — Attendees use Zeabur during practical, instructor-led sessions.
- **Non-profit hackathons** — Participating teams use Zeabur to deploy their projects.
- **Free online courses** — Remote students use Event Codes to complete practical exercises.
- **Open-source and community events** — Technical meetups, presentations, and related demonstration environments.

<span id="paid-and-commercial-events" />

## Paid and Commercial Events

Paid courses, ticketed events, company-funded training, and any event for which a speaker or organizer receives event-related compensation or revenue are not eligible for Event Code sponsorship. Organizations seeking product trial support for a paid or commercial event should submit an application under the [Sales Partner Program](/partner/sales-partner).
