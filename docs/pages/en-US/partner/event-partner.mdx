# Education Partner

The Education Partner program supports **open-source, community, and free educational events** run by instructors, community leaders, hackathon organizers, and educational institutions. Approved Partners may submit each eligible event for an Event Code that gives attendees Zeabur credits.

## Sponsorship Eligibility

Event sponsorship is only available when all of the following are true:

- The event is not run for profit.
- Attendees are not charged.
- Speakers and organizers do not profit from the event.

Meeting these requirements does not guarantee approval. Zeabur reviews every event individually and retains final discretion over sponsorship.

## How It Works

<Steps>

### Apply

Sign up at [partner.zeabur.com](https://partner.zeabur.com) and describe your course or event plan.

### Submit an eligible event

Confirm that the event meets the sponsorship requirements, then submit its details in the Partner Portal.

### Receive an Event Code

The Zeabur team reviews the application within 1–3 business days. Once approved, the Event Code becomes available to distribute to attendees.

### Run your event

Guide attendees through deploying projects on Zeabur during your course, workshop, or hackathon.

</Steps>

## Event Code Mechanism

An Event Code is a unique code that, once redeemed, adds credits to the attendee's account balance. The credits can be spent on any paid service on Zeabur (deployments, servers, AI Hub, etc.):

- Each Event Code is tied to a specific event and has a clear validity window (typically ending at the close of the event day).
- Attendees can redeem by visiting the event sign-up link (`https://zeabur.com/events?code=...`), which redeems automatically upon registration, or by entering the code on the Billing page after logging in.
- See the [Redeem Event Code](/partner/event-partner/redeem-event-code) guide for the full redemption steps you can share with attendees.

<Callout type="info">
  Event Code redemptions do not trigger the Referral Program's commission
  mechanism — Event Code credits are sponsored, not real payments. Referral
  commissions only apply when a user's actual payment succeeds.
</Callout>

## Credit Amount

Each approved Event Code currently provides **US$10 in Zeabur account credit per attendee**.

The credit is added to the attendee's account balance and can be used for deployments, servers, AI Hub, and other paid Zeabur services. The number of supported attendees is reviewed per event.

## Ideal Scenarios

- **Free programming courses** — Students deploy course projects to the cloud.
- **Free technical workshops** — Hands-on events where attendees experience the deployment flow in real time.
- **Non-profit hackathons** — Teams use Zeabur to rapidly deploy their projects.
- **Free online courses** — Remote learners use Event Codes for hands-on practice.
- **Open-source and community events** — Tech meetups and talks paired with demo environments.

## How to Apply

Sign up at [partner.zeabur.com](https://partner.zeabur.com). Partner approval gives you access to the program but does not guarantee sponsorship for every event. Each eligible event must be submitted separately with its event page, expected attendance, dates, and format.

For other questions, feel free to contact us through [Zeabur Support](https://zeabur.com/support).

<span id="paid-and-commercial-events" />

## Paid and Commercial Events

Paid courses, ticketed events, company-funded training, and events where speakers or organizers receive activity-related income are not eligible for Event Code sponsorship.

If you are running a paid or commercial event and would like product trial support, contact us separately through [Zeabur Support](https://zeabur.com/support) to discuss an appropriate arrangement.
