# Partner Program

The Zeabur Partner Program provides structured collaboration models for instructors, event organizers, enterprise consultants, and system integrators supporting education initiatives or Zeabur adoption.

## Two Partnership Models

### Education Partner

For **instructors, community leaders, hackathon organizers, and educational institutions** organizing eligible free, non-profit events. Approved Education Partners may submit each eligible event for individual review and receive an Event Code that grants attendees Zeabur account credits.

- Each event sponsorship application is reviewed separately
- Each approved Event Code currently grants US$10 in account credit per attendee
- Eligible use cases include free workshops, online courses, non-profit hackathons, and community events

[Learn more →](/partner/event-partner)

### Sales Partner

For **enterprise consultants, system integrators, and technology consulting firms**. Help enterprise clients or institutions adopt Zeabur and earn recurring commissions based on the stages you participate in.

- Ideal for large contracts, institutional procurement, and technical consulting
- Two-layer commission: per-deal tiered rate × contribution stage weighting
- Specific rates, thresholds, and terms are individually negotiated in each contract — not publicly disclosed

[Learn more →](/partner/sales-partner)

## How It Differs from the Referral Program

Zeabur also offers a [Referral Program](/rewards/referral) that lets any user earn rewards through referral codes. Key differences:

| Aspect             | Referral Program                    | Partner Program                                       |
| ------------------ | ----------------------------------- | ----------------------------------------------------- |
| Who                | Any user                            | Instructors / Organizers / Consultants / Integrators  |
| How                | Automatic referral code flow        | Manual review and contract                            |
| Support / benefits | Referral code commissions (by tier) | Event sponsorship credits / Sales Partner commissions |
| Terms              | Unified platform terms              | Individually negotiated per contract                  |

<Callout type="info">
  A single transaction can only go through the Referral Program or the Partner
  Program — **they do not stack**.
</Callout>

## How to Apply

Submit an application through the [Partner Portal](https://partner.zeabur.com/apply) based on the relevant partnership type:

- **Education Partner** — Apply for Partner status. After approval, submit each eligible event separately for sponsorship review.
- **Sales Partner** — Provide company information, expected client types, and engagement scale.

The Zeabur team will reach out after receiving your application to discuss terms.
