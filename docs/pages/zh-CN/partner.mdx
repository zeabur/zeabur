# 合作伙伴计划

Zeabur Partner Program 为讲师、活动主办方、企业顾问与系统集成商提供明确的合作模式，分别支持教育活动与企业导入 Zeabur。

## 两种合作模式

### 教育伙伴

适合举办免费、非营利活动的**讲师、社群领袖、Hackathon 主办方与教育机构**。通过 Education Partner 审核后，可针对每一场符合资格的活动单独提交审核，并获取让参与者使用 Zeabur 账户额度的活动码（Event Code）。

- 每一场活动赞助申请均须单独审核
- 审核通过后，目前每位参与者可获得 US$10 Zeabur 账户额度
- 适用于免费工作坊、在线课程、非营利 Hackathon 与社群活动

[了解更多 →](/partner/event-partner)

### 销售伙伴（Sales Partner）

适合**企业顾问、系统集成商、技术顾问公司**。协助企业客户或机构导入 Zeabur，根据实际参与的合作阶段获得经常性分润。

- 适合大型合同、机构采购、技术顾问导入等情境
- 两层分润架构：交易层累进费率 × 贡献阶段权重
- 具体费率、门槛与条件在合同中个别约定，不对外公开

[了解更多 →](/partner/sales-partner)

## 与 Referral Program 的区隔

Zeabur 同时提供 [Referral Program](/rewards/referral)（推荐计划），让所有用户通过推荐码赚取回馈。两者的主要差异：

| 项目        | Referral Program     | 合作伙伴计划                            |
| ----------- | -------------------- | --------------------------------------- |
| 适用对象    | 所有用户             | 讲师 / 活动主办 / 企业顾问 / 系统集成商 |
| 触发方式    | 推荐码自动流程       | 人工审核与合同                          |
| 支持 / 回馈 | 推荐码佣金（依等级） | 活动赞助额度 / Sales Partner 分润       |
| 合同条件    | 平台条款统一         | 每份合作合同个别约定                    |

<Callout type="info">
  同一笔交易只能走 Referral Program 或合作伙伴计划其中一条路径，**两者不叠加**。
</Callout>

## 如何申请

前往 [Partner Portal](https://partner.zeabur.com/apply)，根据合作类型提交申请：

- **教育伙伴** — 先申请 Partner 资格；通过后，再针对每一场符合资格的活动单独提交赞助申请。
- **销售伙伴** — 填写公司信息、预估客户类型与合作规模。

Zeabur 团队会在收到申请后联系你，讨论合作条件。
