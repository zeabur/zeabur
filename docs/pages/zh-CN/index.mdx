# 基本介绍

**Zeabur** 是一个可以帮助你部署服务的平台，无论你使用什么编程语言或开发框架，你都只需要通过几个简单的按钮进行部署。

如有产品问题或需要优先支持，请访问 [Zeabur 支持](https://zeabur.com/support)。

### Zeabur 的优势

#### 方便快捷

对比传统的部署方式，Zeabur 可以让你在几分钟内完成部署，而不需要花费大量的时间去学习部署的相关知识，把时间精力专注于产品的开发。

- 开箱即用的 CI/CD
- 自动识别项目类型
- 快速生成域名
- 多环境隔离

#### 价格可预期，成本可控

Zeabur 提供固定月费的订阅方案与服务器，帮助你规划基础设施预算。实际账单金额取决于你使用的方案、服务器，以及任何按使用量计费的服务。

现有共享集群用户仍按资源使用量计费。详情请参阅[定价方案](/pricing)与[共享集群](/server/shared-cluster)。

#### 一站式整合

Zeabur 提供了强大的一站式整合功能。

你可以在一个项目中同时部署前端、后端、数据库、消息队列、对象存储等各种服务，而不需要分别部署到不同的平台。
