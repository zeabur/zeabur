# 在 Zeabur 上部署 Farm.js

[Farm.js](https://farmjs.dev/) 是一个全栈框架，提供类型安全的文件路由、Server Actions 和流式服务端渲染。它默认使用 React，也支持 Preact、Solid、Vue 和 Svelte。

本文将帮助你在 Zeabur 上部署 Farm.js 应用。

## 步骤一：创建一个 Farm.js 项目

你可以使用下面的命令创建一个 Farm.js 项目并跟随提示进行配置。

<Callout>
    最低要求：Node.js 22.13.0 或更高版本
</Callout>

```bash
# npm
npx @farm.js/create-app@latest my-app
# yarn
yarn create @farm.js/app my-app
# pnpm
pnpm create @farm.js/app my-app
```

<Callout>
    Zeabur 会使用 `package.json` 中的 `start` 脚本启动应用。请确保它运行 `farm build` 生成的服务，即 `"start": "node .farm/.output/server/index.mjs"`（在 Zeabur 上使用 `"start": "farm start"` 也可以）。如果 `farm.config.ts` 中设置了 `deploy.target`，请将其移除，这样构建会生成一个 Node.js 服务。
</Callout>

## 步骤二：部署到 Zeabur

前往 [Zeabur 控制台](https://zeabur.com) 并创建一个新项目。

然后，点击 `Deploy New Service` 按钮，选择从 GitHub 部署。

<Callout>
    如果你是第一次在 Zeabur 上从 GitHub 部署项目，你需要先配置并安装 GitHub 应用。
    你可以在 [这里](/deploy/methods/github-integration) 查看更详细的指南。
</Callout>

当你选择好仓库和分支后，Zeabur 将会自动开始构建你的服务。

Zeabur 会将你的服务识别为 Node.js 项目，运行 `build` 脚本，并使用 `start` 脚本启动服务，所以你不需要做任何额外的配置。Farm.js 服务会监听 Zeabur 提供的 `PORT`。你的部署将会在几分钟内完成。

## 下一步

部署完成后，你可能需要为你的 Farm.js 应用配置域名。

打开服务页面的 "Domain" 标签页，然后点击 "Generate Domain" 或 "Custom Domain"。

关于如何为你的服务绑定域名的更多信息，请参考 [绑定域名](/deploy/networking/public-networking)。
