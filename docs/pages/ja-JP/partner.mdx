# パートナープログラム

Zeabur Partner Program は、講師、イベント主催者、企業コンサルタント、システムインテグレーターを対象に、教育活動の支援と Zeabur 導入支援に関する明確な協業モデルを提供します。

## 2 種類の協業モデル

### 教育パートナー

無料かつ非営利のイベントを開催する**講師、コミュニティリーダー、ハッカソン主催者、教育機関**を対象としています。Education Partner として承認された後、条件を満たすイベントごとにスポンサー申請を提出し、参加者に Zeabur アカウントクレジットを提供するイベントコード (Event Code) を取得できます。

- イベントスポンサー申請はイベントごとに個別審査
- 承認されたイベントコードでは、現在 1 人あたり US$10 の Zeabur アカウントクレジットを提供
- 無料のワークショップ、オンライン講座、非営利のハッカソン、コミュニティイベントなどが対象

[詳しく見る →](/partner/event-partner)

### セールスパートナー (Sales Partner)

**企業コンサルタント、システムインテグレーター、テクノロジーコンサルティング企業**に適しています。企業顧客や機関の Zeabur 導入を支援し、実際に関与した協業フェーズに応じて継続的なレベニューシェアを獲得します。

- 大型契約、機関調達、テクニカルコンサルティング導入などのケースに適合
- 2 階層のレベニューシェア構造：取引レート（累進制）× 貢献フェーズの重み
- 具体的なレート、閾値、条件は個別の契約で定め、対外的には公開しません

[詳しく見る →](/partner/sales-partner)

## Referral Program との違い

Zeabur では [Referral Program](/rewards/referral)（リファラルプログラム）も提供しており、すべてのユーザーが推薦コードを通じて報酬を得ることができます。両者の主な違いは以下のとおりです：

| 項目        | Referral Program                           | パートナープログラム                                                  |
| ----------- | ------------------------------------------ | --------------------------------------------------------------------- |
| 対象        | すべてのユーザー                           | 講師 / イベント主催者 / 企業コンサルタント / システムインテグレーター |
| トリガー    | 推薦コードによる自動フロー                 | 人手による審査と契約                                                  |
| 支援 / 特典 | 推薦コードのコミッション（ランクに応じる） | イベントスポンサークレジット / セールスパートナーのレベニューシェア   |
| 契約条件    | プラットフォーム利用規約で一律             | 協業契約ごとに個別に交渉                                              |

<Callout type="info">
  同一の取引は Referral Program またはパートナープログラムのいずれか 1
  つの経路のみを通ることができ、**両者の併用はできません**。
</Callout>

## 応募方法

[Partner Portal](https://partner.zeabur.com/apply) から、該当する協業タイプの申請を提出してください：

- **教育パートナー** — まず Partner 資格を申請します。承認後、条件を満たすイベントごとにスポンサー申請を提出します。
- **セールスパートナー** — 会社情報、想定される顧客タイプと協業規模を記入。

Zeabur チームは応募を受領後、ご連絡のうえ協業条件について協議いたします。
