# はじめに

**Zeabur** は、ワンクリックでサービスをデプロイできるプラットフォームです。
使用するプログラミング言語やフレームワークに関係なく利用可能です。

製品に関する質問や優先サポートについては、[Zeabur サポート](https://zeabur.com/support)をご利用ください。

### Zeabur の利点

#### 便利で高速

従来のデプロイメント方法と比べ、Zeabur を使うと、デプロイメントに関連する多くの知識を学ぶことなく、わずか数分でデプロイメントを完了できます。これにより、製品開発に時間とエネルギーを集中させることができます。

- すぐに使える CI/CD
- 自動で行われるプロジェクトタイプの認識
- 迅速なドメイン生成
- 複数環境の隔離

#### 予測可能な料金、コントロール可能なコスト

Zeabur は、インフラの予算を立てやすくするため、月額固定のサブスクリプションプランとサーバーを提供しています。請求総額は、ご利用のプラン、サーバー、および従量課金のサービスによって異なります。

既存の共有クラスタユーザーには、引き続きリソース使用量に基づいて課金されます。詳しくは[料金プラン](/pricing)と[共有クラスタ](/server/shared-cluster)をご覧ください。

#### オールインワン統合

Zeabur は、強力なオールインワン統合機能を提供します。

フロントエンド、バックエンド、データベース、メッセージキュー、オブジェクトストレージなど、様々なサービスを一つのプロジェクトでデプロイできます。別々のプラットフォームに個別にデプロイする必要はありません。
