# 教育パートナー (Education Partner)

教育パートナープログラムは、**講師、コミュニティリーダー、ハッカソン主催者、教育機関**が実施するオープンソース、コミュニティ、無料教育イベントを支援します。Partner として承認された後、条件を満たす各イベントについてイベントコード (Event Code) を申請できます。

## スポンサー対象条件

イベントスポンサーを申請するには、以下の条件をすべて満たす必要があります：

- イベントが営利を目的としていないこと。
- 参加者から料金を徴収しないこと。
- 講師・主催者がイベントから利益を得ないこと。

条件を満たしても承認が保証されるものではありません。Zeabur はイベントごとに審査し、スポンサー提供の最終判断を行います。

## 仕組み

<Steps>

### 応募

[partner.zeabur.com](https://partner.zeabur.com) から応募し、講座やイベントの計画を説明します。

### 条件を満たすイベントを申請

スポンサー条件を確認し、Partner Portal からイベント情報を送信します。

### イベントコードを受け取る

Zeabur チームが 1〜3 営業日以内に審査します。承認後、イベントコードを参加者へ配布できるようになります。

### イベントを実施

講座、ワークショップ、ハッカソンなどで、参加者が Zeabur を使ってプロジェクトをデプロイできるよう案内します。

</Steps>

## イベントコードの仕組み

イベントコードは、引き換えると参加者のアカウント残高にイベントクレジットが追加される専用コードです。クレジットは Zeabur 上のあらゆる有料サービス（デプロイ、サーバー、AI Hub など）に利用できます：

- 各イベントコードは特定のイベントに紐付けられ、明確な有効期間（通常はイベント当日の終了時まで）があります。
- 参加者はイベント登録リンク（`https://zeabur.com/events?code=...`）から登録することで自動的に引き換えられるほか、ログイン後に請求ページから手動で引き換えることもできます。
- 参加者向けの詳しい引き換え手順は [イベントコードの引き換え](/partner/event-partner/redeem-event-code) をご参照ください。

<Callout type="info">
  イベントコードの引き換えは Referral Program
  のコミッション機構をトリガーしません。イベントクレジットは協賛であり、実際の支払いではないためです。リファラルコミッションは、ユーザーが実際に支払いを完了した場合にのみ計算されます。
</Callout>

## スポンサー額

現在、承認されたイベントコードを引き換えた参加者には、1 人あたり **US$10 の Zeabur アカウントクレジット**が付与されます。

クレジットは参加者のアカウント残高に追加され、デプロイ、サーバー、AI Hub などの有料 Zeabur サービスに使用できます。支援人数はイベントごとに審査されます。

## 適したシナリオ

- **無料のプログラミング講座** — 受講生が講座のプロジェクトをクラウドにデプロイ。
- **無料のテクニカルワークショップ** — デプロイフローをその場で体験できるハンズオンイベント。
- **非営利のハッカソン** — 参加チームが Zeabur を使って作品を素早くデプロイ。
- **無料のオンライン講座** — リモート受講生が実習できるようイベントコードを配布。
- **オープンソース・コミュニティイベント** — 技術コミュニティの勉強会や LT 会とデモ環境を組み合わせて実施。

## 応募方法

[partner.zeabur.com](https://partner.zeabur.com) でアカウントを作成してください。Partner の承認はプログラムへの参加を認めるもので、各イベントのスポンサーを保証するものではありません。条件を満たすイベントごとに、イベントページ、想定参加人数、日程、形式を提出して審査を受ける必要があります。

その他のご質問は、[Zeabur サポート](https://zeabur.com/support)までお気軽にお問い合わせください。

## 有料・商用イベント

有料講座、チケット制イベント、企業が費用を負担する研修、講師または主催者がイベント関連の収入を得る活動は、イベントコードスポンサーの対象外です。

有料または商用イベントで製品トライアル支援をご希望の場合は、[Zeabur サポート](https://zeabur.com/support)から個別にお問い合わせください。
