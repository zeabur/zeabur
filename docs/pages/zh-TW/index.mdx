# 基本介紹

**Zeabur** 是一個可以幫助你部署服務的平台，而且只需要透過幾個簡單的按鈕即可完成，無論你使用什麼程式語言或開發框架。

如有產品問題或需要優先支援，請前往 [Zeabur 支援](https://zeabur.com/support)。

### Zeabur 的優勢

#### 方便快捷

對比傳統的部署方式，Zeabur 可以讓你在幾分鐘內完成部署，而不需要花費大量的時間去學習部署的相關知識，把時間精力專注於產品的開發。

- 開箱即用的 CI/CD
- 自動識別專案類型
- 快速生成網域
- 多環境隔離

#### 價格可預期，成本可控

Zeabur 提供固定月費的訂閱方案與伺服器，協助你規劃基礎建設預算。實際帳單金額取決於你使用的方案、伺服器，以及任何按用量計費的服務。

既有共享叢集使用者仍依資源使用量計費。詳情請參閱[定價方案](/pricing)與[共享叢集](/server/shared-cluster)。

#### 一站式整合

Zeabur 提供了強大的一站式整合功能。

你可以在一個專案中同時部署前端、後端、資料庫、消息佇列、物件儲存等各種服務，而不需要分別部署到不同的平台。
