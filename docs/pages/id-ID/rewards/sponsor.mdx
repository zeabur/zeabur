# Sponsor

## Apa itu Sponsorship?

Sponsorship dari Zeabur memberikan manfaat berikut:

- Gratis Developer Plan selama satu bulan untuk semua kontributor.

- Kredit untuk kontributor, yang besarnya bervariasi tergantung skala proyek dan kontribusi masing-masing.

## Kriteria Sponsorship

- Proyek harus bersifat non-komersial dan sepenuhnya open source.

- Proyek wajib menampilkan banner Zeabur di footer situs web proyek dan di file `README.md`.

Anda dapat menemukan materinya di [halaman referral](https://dash.zeabur.com/account/referral) pada dashboard kami.

[![Deploy on Zeabur](https://zeabur.com/deployed-on-zeabur-dark.svg)](https://dash.zeabur.com/account/referral)

## Cara Mengajukan Sponsorship

- Sponsorship terbuka untuk setiap proyek yang memenuhi kriteria di atas.

- Untuk mengajukan, ikuti langkah-langkah berikut:

    - Pastikan proyek Anda memenuhi semua kriteria yang tercantum.

    - Ajukan permintaan melalui [Zeabur Support](https://zeabur.com/support), sertakan tautan proyek Anda dan deskripsi singkat.
