# Harga

Zeabur menawarkan empat tingkat langganan ditambah opsi Enterprise yang dapat disesuaikan. Setiap tingkat mencakup fitur platform dan batas sumber daya tertentu — lihat [Harga](/pricing) untuk daftar paket lengkap.

## Tingkat Langganan

- **[Free Plan](/pricing/free-plan)** — US$0/bulan
- **[Dev Plan](/pricing/dev-plan)** — US$5/bulan (uji coba gratis 14 hari)
- **[Pro Plan](/pricing/pro-plan)** — US$19/bulan (uji coba gratis 14 hari)
- **[Team Plan](/pricing/team-plan)** — US$79/bulan untuk 3 kursi (+US$24/kursi)
- **Enterprise** — [hubungi kami](https://zeabur.com/support)

Untuk perbandingan fitur lengkap, kunjungi [zeabur.com/pricing](https://zeabur.com/pricing).

## Pengembalian Dana

Untuk masalah pengembalian dana apa pun, silakan hubungi kami melalui [Zeabur Support](https://zeabur.com/support).

Untuk **Dev Plan** atau **Pro Plan**, Anda dapat membatalkan langganan kapan saja. Setelah dibatalkan, Anda tetap dapat menggunakan semua fitur paket saat ini hingga akhir siklus tagihan berjalan, setelah itu akun Anda akan otomatis beralih ke paket Free. Biaya yang sudah ditagihkan untuk siklus berjalan tidak akan dikembalikan.

Untuk **Team Plan**, Anda dapat membatalkan langganan kapan saja. Setelah dibatalkan, tim Anda tetap dapat menggunakan semua fitur Team hingga akhir siklus tagihan berjalan, setelah itu workspace akan otomatis di-downgrade. Biaya yang sudah ditagihkan untuk siklus berjalan tidak akan dikembalikan.

Untuk pengguna **Server**, Zeabur tidak lagi mendukung pengembalian dana untuk server yang dibuat atau diperpanjang setelah 21 Juli 2025. Agar tidak ditagih pada siklus tagihan berikutnya, Anda dapat menonaktifkan pengaturan perpanjangan otomatis.

> Harap diperhatikan, ketentuan ini hanya berlaku untuk server yang dibuat atau diperpanjang setelah 21 Juli 2025.

![disable auto renewal](/billing/pricing/auto-renewal.png)

Anda dapat memilih untuk menerima pengembalian dana sebagai kredit Zeabur atau ke metode pembayaran asli Anda. Jika Anda memilih kredit Zeabur, pengembalian dana biasanya diproses seketika setelah disetujui. Jika Anda memilih pengembalian ke metode pembayaran asli, prosesnya dapat memakan waktu hingga 7 hari, dan Anda perlu menanggung biaya transaksi Stripe, yaitu sekitar 30% dari jumlah yang dikembalikan.

## Pertanyaan yang Sering Diajukan

### Apa hubungan antara VPS dan paket langganan?

VPS adalah server yang Anda beli dari penyedia cloud dengan harga diskon melalui Zeabur. Paket langganan menyediakan layanan manajemen tambahan di atas VPS Anda, termasuk dashboard terpadu, pemantauan, backup, AI Agent, dan dukungan teknis.

### Mengapa saya sebaiknya membeli VPS melalui Zeabur?

Zeabur menawarkan harga diskon eksklusif dari penyedia cloud terkemuka, ditambah platform manajemen terpadu. Anda mendapatkan harga lebih rendah, penyiapan instan, pemantauan bawaan, backup otomatis, dan dukungan prioritas — semuanya di satu tempat.

### Paket langganan mana yang tepat untuk saya?

Free Plan cocok untuk memulai dengan akses dashboard dasar. Dev Plan ideal untuk developer perorangan yang membutuhkan pemantauan lengkap, backup, dan AI Agent. Pro Plan menambahkan log forwarding, kuota yang lebih besar, dan dukungan prioritas — direkomendasikan untuk beban kerja produksi. Team Plan dirancang untuk tim yang mengelola banyak server dengan manajemen peran dan izin.

### Bisakah saya menggunakan Zeabur tanpa kartu kredit?

Ya. Anda dapat membeli kredit prabayar tanpa kartu kredit. Alipay juga tersedia sebagai metode pembayaran alternatif. Lihat [halaman langganan](/subscription) untuk detailnya.

### Apakah saya akan mendapatkan tanda terima?

Saat Anda melakukan pembayaran, Anda akan menerima email dengan faktur dan tanda terima terlampir. Anda juga dapat melihat riwayat tagihan di [halaman tagihan](https://zeabur.com/account/billing).

Jika Anda memerlukan informasi tagihan khusus pada faktur (misalnya nama perusahaan, nomor identitas pajak, atau alamat), Anda harus berlangganan **Dev Plan** atau lebih tinggi. Jika Anda memerlukan faktur resmi, Anda harus berlangganan **Team Plan**.

### Penyedia cloud apa saja yang didukung?

Saat ini kami mendukung AWS (Lightsail), Hetzner, DigitalOcean, Tencent Cloud, Linode, Alibaba Cloud, dan Google Cloud (GCP). Kami terus menambahkan penyedia lainnya.
