# Profil Pendaftar


Pendaftaran domain memerlukan informasi kontak WHOIS. Profil pendaftar memungkinkan Anda menyimpan informasi ini sekali dan menggunakannya kembali untuk beberapa pembelian domain.

## Kolom Profil

| Kolom | Wajib | Deskripsi |
|-------|----------|-------------|
| Nama Depan | Ya | Nama depan pendaftar |
| Nama Belakang | Ya | Nama belakang pendaftar |
| Email | Ya | Email kontak (juga digunakan untuk verifikasi pendaftar) |
| Telepon | Ya | Nomor telepon kontak |
| Alamat Baris 1 | Ya | Alamat jalan |
| Alamat Baris 2 | Tidak | Apartemen, unit, dll. |
| Kota | Ya | Kota |
| Provinsi | Ya | Negara bagian atau provinsi |
| Negara | Ya | Negara (pilih dari dropdown) |
| Kode Pos | Ya | Kode pos atau ZIP |
| Organisasi | Tidak | Nama perusahaan atau organisasi |

## Membuat Profil

<Steps>

### Buka Tab Profil

Buka bagian **Domain** di sidebar dan pilih tab **Profil**.

### Isi Formulir

Klik **Buat Profil** dan isi kolom yang wajib diisi. Pilih negara dari dropdown yang dapat dicari.

### Simpan

Klik **Simpan**. Profil baru langsung tersedia untuk digunakan saat mendaftarkan domain.

</Steps>

## Profil Default

Jadikan satu profil sebagai **default** dengan mengklik ikon bintang. Profil default akan otomatis terpilih di pemilih profil pendaftar saat pembelian domain. Anda tetap dapat beralih ke profil lain saat checkout.

## Mengedit dan Menghapus

- Klik **ikon edit** pada kartu profil untuk memperbarui kolomnya.
- Klik **ikon hapus** untuk menghapus profil.

<Callout type="warning">
  Menghapus profil tidak memengaruhi domain yang sudah didaftarkan dengan profil tersebut. Domain yang sudah ada tetap menggunakan informasi kontak yang dikirimkan saat pendaftaran.
</Callout>

## Membuat Profil Langsung

Anda juga dapat membuat profil baru langsung dari dialog pembelian domain tanpa harus membuka tab Profil. Profil baru akan disimpan ke akun Anda dan dapat digunakan kembali untuk pendaftaran berikutnya.
