# Mulai Cepat

Panduan ini akan membantu Anda mengirim email pertama menggunakan Zeabur Email dalam hitungan menit.

## Prasyarat

Sebelum memulai, Anda memerlukan:

1. Akun Zeabur
2. Layanan Zeabur Email yang sudah diaktifkan di konsol Zeabur Anda
3. Setidaknya satu domain pengirim yang sudah terverifikasi
4. API key

## Langkah 1: Buat API Key

import { Callout, Steps } from 'nextra/components'

<Steps>

### Masuk ke Konsol Zeabur

Kunjungi [Dashboard Zeabur](https://zeabur.com) dan masuk ke akun Anda.

### Buka Halaman Manajemen Zeabur Email

Temukan layanan Zeabur Email di konsol, lalu masuk ke halaman manajemennya.

### Buat API Key Baru

1. Klik tombol "Buat Kunci API"
2. Pilih jenis izin:
   - **Baca Saja**: Hanya dapat memeriksa status email
   - **Kirim Saja**: Dapat mengirim email dan memeriksa status (disarankan untuk production)
   - **Akses Penuh**: Mencakup semua izin operasi
3. Opsional: Batasi izin domain (hanya dapat mengirim dari domain tertentu)
4. Klik "Buat"

<Callout type="warning">
  Segera simpan API key Anda setelah dibuat — key hanya ditampilkan satu kali!
</Callout>

</Steps>

## Langkah 2: Verifikasi Domain Anda

Untuk mengirim email, Anda harus memverifikasi domain pengirim terlebih dahulu:

<Steps>

### Tambahkan Domain

Di bagian "Domain" pada halaman manajemen Zeabur Email, klik "Tambah Domain".

### Konfigurasi Record DNS

Sistem akan membuat record DKIM, SPF, dan DMARC. Anda perlu menambahkan record tersebut di penyedia DNS domain Anda.

### Tunggu Verifikasi

Setelah menambahkan record DNS, klik tombol "Verifikasi". Verifikasi biasanya memerlukan waktu beberapa menit hingga beberapa jam.

</Steps>

## Langkah 3: Kirim Email Pertama Anda

Setelah domain Anda terverifikasi, Anda siap mengirim email!

### Menggunakan cURL

```bash
curl -X POST https://api.zeabur.com/api/v1/zsend/emails \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "from": "hello@yourdomain.com",
    "to": ["user@example.com"],
    "subject": "Hello from Zeabur Email!",
    "html": "<h1>Hello!</h1><p>This is my first email from Zeabur Email.</p>",
    "text": "Hello! This is my first email from Zeabur Email."
  }'
```

### Menggunakan JavaScript/Node.js

```javascript
const response = await fetch('https://api.zeabur.com/api/v1/zsend/emails', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify({
    from: 'hello@yourdomain.com',
    to: ['user@example.com'],
    subject: 'Hello from Zeabur Email!',
    html: '<h1>Hello!</h1><p>This is my first email from Zeabur Email.</p>',
    text: 'Hello! This is my first email from Zeabur Email.'
  })
});

const data = await response.json();
console.log('Email sent:', data);
```

### Menggunakan Python

```python
import requests

response = requests.post(
    'https://api.zeabur.com/api/v1/zsend/emails',
    headers={
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_API_KEY'
    },
    json={
        'from': 'hello@yourdomain.com',
        'to': ['user@example.com'],
        'subject': 'Hello from Zeabur Email!',
        'html': '<h1>Hello!</h1><p>This is my first email from Zeabur Email.</p>',
        'text': 'Hello! This is my first email from Zeabur Email.'
    }
)

print('Email sent:', response.json())
```

### Menggunakan Go

```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "from":    "hello@yourdomain.com",
        "to":      []string{"user@example.com"},
        "subject": "Hello from Zeabur Email!",
        "html":    "<h1>Hello!</h1><p>This is my first email from Zeabur Email.</p>",
        "text":    "Hello! This is my first email from Zeabur Email.",
    }

    jsonData, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST", "https://api.zeabur.com/api/v1/zsend/emails", bytes.NewBuffer(jsonData))
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer YOUR_API_KEY")

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    fmt.Println("Email sent! Status:", resp.Status)
}
```
