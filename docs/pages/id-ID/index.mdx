# Pengenalan

**Zeabur** adalah platform yang membantu Anda men-deploy layanan dengan satu klik,
apa pun bahasa pemrograman dan framework yang Anda gunakan.

Untuk pertanyaan seputar produk dan dukungan prioritas, kunjungi [Zeabur Support](https://zeabur.com/support).

### Keunggulan Zeabur

#### Praktis dan Cepat

Dibandingkan dengan metode deployment tradisional, Zeabur memungkinkan Anda menyelesaikan deployment hanya dalam beberapa menit tanpa harus menghabiskan banyak waktu mempelajari seluk-beluk deployment. Dengan begitu, Anda dapat memusatkan waktu dan tenaga untuk pengembangan produk.

- CI/CD yang siap pakai
- Pengenalan jenis proyek secara otomatis
- Pembuatan domain secara cepat
- Isolasi untuk beberapa environment

#### Harga yang Dapat Diprediksi, Biaya yang Terkendali

Zeabur menawarkan paket langganan dan server dengan harga bulanan tetap untuk membantu Anda merencanakan anggaran infrastruktur. Total tagihan Anda bergantung pada paket, server, dan layanan apa pun yang ditagih berdasarkan pemakaian.

Pengguna shared cluster yang sudah ada tetap ditagih berdasarkan pemakaian sumber daya. Lihat [Paket Harga](/pricing) dan [Shared Cluster](/server/shared-cluster) untuk detailnya.

#### Integrasi All-in-One

Zeabur menyediakan kemampuan integrasi all-in-one yang andal.

Anda dapat men-deploy berbagai layanan seperti front-end, back-end, database, message queue, dan object storage dalam satu proyek, tanpa harus men-deploy-nya secara terpisah ke platform yang berbeda-beda.
