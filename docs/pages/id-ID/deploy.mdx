# Deployment & Layanan Inti

Bagian ini mencakup semua metode deployment Zeabur, konfigurasi layanan, dan fitur manajemen proyek. Setiap judul menjawab pertanyaan tertentu agar mudah dijadikan referensi cepat.

## Dari Mana Deployment Dimulai?

Semua layanan di Zeabur berada di dalam sebuah "Proyek". Satu proyek dapat berisi frontend, backend, database, dan lainnya.

- [Buat Proyek](/deploy/create/create-project) — Membuat dan mengelola proyek
- [Buat Layanan](/deploy/create/create-service) — Menambahkan layanan ke proyek
- [Cara Kerja Deploy](/deploy/how-deploys-work) — Pelajari bagaimana Zeabur mendeteksi bahasa dan melakukan build secara otomatis

## Apa yang Memicu Redeploy?

- **GitHub Push**: Secara default, setiap push ke branch yang terhubung akan memicu deployment baru.
- **Pemicu Manual**: Klik "Deploy Ulang" di Dashboard.
- **Watch Paths**: Konfigurasikan agar deployment hanya dipicu ketika path tertentu berubah. Lihat [Watch Paths](/deploy/config/watch-paths).

## Bagaimana Cara Mengatur Environment Variables?

Di tab "Konfigurasi" layanan, Anda dapat menambah, mengedit, dan menghapus environment variables. Zeabur juga mendukung referensi variabel antar layanan.

→ [Environment Variables](/deploy/config/environment-variables)
