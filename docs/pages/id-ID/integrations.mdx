# Integrasi

Zeabur menyediakan integrasi bawaan dengan layanan pihak ketiga, sehingga Anda dapat mengaktifkan kemampuan backend yang andal langsung di dalam proyek Anda — tanpa perlu deployment terpisah.

## Integrasi yang Tersedia

### [InsForge](/id-ID/integrations/insforge/overview)

Alternatif Supabase yang agent-native, memungkinkan AI agent membangun dan mengelola aplikasi full-stack secara mandiri. Dilengkapi database PostgreSQL, autentikasi JWT, penyimpanan file yang kompatibel dengan S3, serverless edge function, serta dukungan protokol MCP untuk integrasi dengan AI IDE.

- **Kategori**: Backend / BaaS
- **Penagihan**: Bayar sesuai pemakaian, ditagih terpisah
- **Situs web**: [insforge.dev](https://insforge.dev)
