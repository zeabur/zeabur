# Program Partner

Program Partner Zeabur menyediakan model kolaborasi yang terstruktur bagi konsultan perusahaan, system integrator, dan firma konsultan teknologi yang membantu perusahaan dan institusi mengadopsi Zeabur.

## Sales Partner

Ditujukan bagi **konsultan perusahaan, system integrator, dan firma konsultan teknologi**. Bantu klien perusahaan atau institusi mengadopsi Zeabur dan dapatkan komisi berulang berdasarkan tahapan yang Anda ikuti.

- Ideal untuk kontrak besar, pengadaan institusi, dan konsultasi teknis
- Komisi dua lapis: tarif bertingkat per transaksi × bobot tahapan kontribusi
- Tarif, ambang batas, dan ketentuan spesifik dinegosiasikan secara individual dalam setiap kontrak — tidak diungkapkan secara publik

[Pelajari lebih lanjut →](/partner/sales-partner)

## Perbedaan dengan Program Referral

Zeabur juga menawarkan [Program Referral](/rewards/referral) yang memungkinkan setiap pengguna mendapatkan hadiah melalui kode referral. Perbedaan utamanya:

| Aspek              | Program Referral                    | Program Partner                                       |
| ------------------ | ----------------------------------- | ----------------------------------------------------- |
| Siapa              | Semua pengguna                      | Konsultan / Integrator                                |
| Cara               | Alur kode referral otomatis         | Peninjauan manual dan kontrak                         |
| Dukungan / manfaat | Komisi kode referral (per tingkat)  | Komisi Sales Partner                                  |
| Ketentuan          | Ketentuan platform yang seragam     | Dinegosiasikan secara individual per kontrak          |

<Callout type="info">
  Satu transaksi hanya dapat melalui Program Referral atau Program Partner
  — **keduanya tidak dapat digabungkan**.
</Callout>

## Cara Mendaftar

Ajukan pendaftaran melalui [Partner Portal](https://partner.zeabur.com/apply) dengan menyertakan informasi perusahaan, jenis klien yang diharapkan, dan skala kerja sama.

Tim Zeabur akan menghubungi Anda setelah menerima pendaftaran untuk membahas ketentuannya.
