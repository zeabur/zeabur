# Hadiah & Referral

Zeabur menawarkan berbagai program hadiah agar Anda dapat memperoleh manfaat sambil menggunakan dan mempromosikan platform.

- [Program Referral](/rewards/referral) — Bagikan kode referral Anda untuk memberikan diskon kepada teman dan dapatkan komisi
- [Program Hadiah Kontribusi](/rewards/contribution) — Kontribusikan template atau terjemahan untuk mendapatkan kredit pemakaian gratis
- [Sponsorship Open Source](/rewards/sponsor) — Ajukan sponsorship Zeabur untuk proyek open source Anda
- [Tukarkan Kartu Prabayar](/partner/sales-partner/redeem-card) — Tukarkan kartu prabayar ke saldo akun Anda
