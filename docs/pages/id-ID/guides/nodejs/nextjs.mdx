# Deploy Next.js

Deploy aplikasi Next.js di Zeabur.

### Langkah 1: Membuat Aplikasi Next.js (Opsional)

- Node.js v14 atau versi yang lebih baru.

Buka terminal Anda dan jalankan
```bash
npx create-next-app@latest
# atau
yarn create next-app
# atau
pnpm create next-app
```

Inisialisasi repositori GitHub untuk proyek ini dan unggah ke GitHub Anda.

### Langkah 2: Deploy Aplikasi Next.js

Klik tombol **Deploy Layanan** atau **Tambah Layanan Baru**, lalu pilih **Deploy dari kode sumber Anda**.

![deploy](/deploy/common/select-service.en-US.png)

Cari repositori aplikasi Next.js Anda, klik import, dan aplikasi Next.js Anda akan mulai di-deploy.
