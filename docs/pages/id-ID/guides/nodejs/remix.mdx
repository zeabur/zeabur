# Deploy Remix

Deploy aplikasi Remix di Zeabur.

### Langkah 1: Membuat Aplikasi Remix (Opsional)

- Node.js v14 atau versi yang lebih baru.

Buka terminal Anda dan jalankan
```bash
npx create-remix@latest
```

Inisialisasi repositori GitHub untuk proyek ini dan unggah ke GitHub Anda.

### Langkah 2: Deploy Aplikasi Remix

Klik tombol **Deploy Layanan** atau **Tambah Layanan Baru**, lalu pilih **Deploy dari kode sumber Anda**.

![deploy](/deploy/common/select-service.en-US.png)

Cari repositori aplikasi Remix Anda, klik import, dan aplikasi Remix Anda akan mulai di-deploy.
