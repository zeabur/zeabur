# Deploy Vite

Deploy aplikasi Vite di Zeabur.

### Langkah 1: Membuat Aplikasi Vite (Opsional)

- Node.js v14.18 atau versi yang lebih baru.

Buka terminal Anda dan jalankan
```bash
npx create vite@latest
# atau
yarn create vite
# atau
pnpm create vite
```

Inisialisasi repositori GitHub untuk proyek ini dan unggah ke GitHub Anda.

### Langkah 2: Deploy Aplikasi Vite

Klik tombol **Deploy Layanan** atau **Tambah Layanan Baru**, lalu pilih **Deploy dari kode sumber Anda**.

![deploy](/deploy/common/select-service.en-US.png)

Cari repositori aplikasi Vite Anda, klik import, dan aplikasi Vite Anda akan mulai di-deploy.
