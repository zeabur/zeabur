# Deploy Aplikasi Express

[Express](https://expressjs.com/) adalah framework aplikasi web Node.js yang minimalis dan fleksibel, serta menyediakan serangkaian fitur yang lengkap untuk aplikasi web dan seluler.

Deploy aplikasi Express Anda di Zeabur dengan satu klik.

### Langkah 1: Membuat Aplikasi Express (Opsional)

- Node.js sudah terinstal di komputer Anda.
- Gunakan express-generator atau buat secara manual.

```bash
# Gunakan express-generator
npx express-generator
```

Anda dapat melihat petunjuk yang lebih detail di [dokumentasi resmi Express](https://expressjs.com/en/starter/installing.html).

Inisialisasi repositori GitHub untuk proyek ini dan unggah ke GitHub Anda.

### Langkah 2: Deploy

Klik tombol **Tambah Layanan Baru**, lalu pilih **Deploy dari kode sumber Anda**.

![deploy](/deploy/common/select-service.en-US.png)

Cari repositori aplikasi Express Anda, klik import, dan aplikasi Express Anda akan mulai di-deploy.
