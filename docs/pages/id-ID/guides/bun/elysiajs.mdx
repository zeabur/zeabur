# Deploy Aplikasi ElysiaJS

[ElysiaJS](https://elysiajs.com) adalah framework web Bun yang cepat dan ramah.

Dokumentasi ini akan menunjukkan cara men-deploy aplikasi ElysiaJS di Zeabur dalam waktu satu menit.

## Langkah 1: Membuat Aplikasi ElysiaJS

### Metode 1: Bootstrap dengan Bun

#### Menginstal Bun

Elysia berbasis [Bun](https://bun.sh/), jadi Anda perlu menginstal Bun terlebih dahulu.

```bash
curl https://bun.sh/install | bash
```

#### Bootstrap Aplikasi ElysiaJS

```bash
bun create elysia app-name
```

Setelah itu, Anda akan mendapatkan aplikasi ElysiaJS di direktori `app-name`.

```bash
cd app-name
bun run dev
```

Sekarang, Anda dapat mengunjungi http://localhost:8080 untuk melihat hasilnya.

#### Mengunggah ke GitHub

Jika Anda ingin men-deploy aplikasi ElysiaJS Anda di Zeabur, Anda perlu mengunggah kode Anda ke GitHub terlebih dahulu.

Cukup buat repositori baru di GitHub, lalu push kode Anda ke repositori tersebut. Lihat petunjuk yang lebih detail [di sini](https://docs.github.com/en/github/importing-your-projects-to-github/adding-an-existing-project-to-github-using-the-command-line).

### Metode 2: Menggunakan Template Zeabur

Kami telah menyiapkan [template](https://github.com/zeabur/elysia-starter) untuk aplikasi ElysiaJS. Anda dapat menggunakan template tersebut dengan mengklik tombol **Use this template**.

![Use this template](/guides/bun/elysia/template.png)

## Langkah 2: Deploy Aplikasi ElysiaJS

Klik tombol **Deploy Layanan** atau **Tambah Layanan Baru**, lalu pilih **Deploy dari kode sumber Anda**.

![deploy](/deploy/common/select-service.en-US.png)

Cari repositori aplikasi ElysiaJS Anda, klik import, dan aplikasi ElysiaJS Anda akan otomatis mulai di-deploy.

## Langkah Selanjutnya

Setelah deployment selesai, Anda mungkin perlu mengonfigurasi nama domain untuk aplikasi ElysiaJS Anda.

Buka tab "Domain" di halaman layanan dan klik "Generate Domain" atau "Domain Kustom".

Untuk informasi lebih lanjut tentang cara menghubungkan domain ke layanan Anda, silakan lihat [Menghubungkan domain](/deploy/networking/public-networking).
