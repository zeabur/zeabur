# Ikhtisar Platform

**Zeabur** adalah platform deployment cloud berbasis AI yang membuat aplikasi Anda online dalam hitungan menit — tanpa perlu repot mengelola server, mengonfigurasi CI/CD, atau mengurus infrastruktur.

## Kemampuan Inti

### Deployment Otomatis

- **Deteksi bahasa dan framework secara otomatis** — Push kode Anda dan Zeabur akan otomatis mengenali Node.js, Python, Go, Java, .NET, Rust, dan lainnya, lalu memilih strategi build yang optimal.
- **CI/CD siap pakai** — Setiap `git push` otomatis memicu build dan deployment, tanpa konfigurasi apa pun.
- **Marketplace Template** — Ratusan template siap pakai untuk men-deploy WordPress, n8n, PostgreSQL, dan layanan populer lainnya dengan satu klik.

### Asisten AI

Zeabur memiliki Asisten AI (Agent) bawaan yang memungkinkan Anda menjelaskan kebutuhan Anda dengan bahasa sehari-hari. Asisten ini akan secara otomatis membuat proyek, men-deploy layanan, mengonfigurasi environment variables, dan memasang domain.

### Integrasi All-in-One

Deploy frontend, backend, database, message queue, dan object storage Anda dalam satu proyek — tidak perlu menyebarkan layanan ke berbagai platform. Layanan dapat berkomunikasi melalui jaringan privat, dan environment variables dapat saling mereferensikan.

### Isolasi Multi-Environment

Setiap proyek mendukung beberapa environment (misalnya Production, Staging) yang sepenuhnya terisolasi satu sama lain, sehingga alur kerja pengembangan dan pengujian menjadi lebih efisien.

### Infrastruktur Fleksibel

- **Shared Cluster** (sudah tidak digunakan lagi) — Cocok untuk memulai dengan cepat tanpa perlu mengelola server. Proyek baru tidak dapat lagi dibuat di shared cluster.
- **Server** — Gunakan mesin Anda sendiri (BYO Server) dengan kendali penuh. Lihat [Server](/server).
