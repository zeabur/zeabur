# Mulai Sesuai Kebutuhan

Tidak yakin harus mulai dari mana? Pilih jalur yang paling sesuai dengan situasi Anda.

## 🧪 Saya Hanya Ingin Mencoba

Deploy dari template dengan satu klik — tanpa perlu menulis kode.

1. Telusuri [Marketplace Template](https://zeabur.com/templates) dan pilih yang menarik.
2. Klik "Deploy", pilih region, lalu tunggu beberapa detik.
3. Setelah layanan online, buka tab "Domain" untuk membuat URL gratis untuk pengujian.

**Bacaan yang direkomendasikan:** [Mulai Cepat](./quick-start) · [Template](/template)

---

## 💻 Saya Punya Proyek untuk Di-deploy

Push kode Anda dari GitHub ke Zeabur — sebagian besar bahasa dan framework didukung.

1. Di proyek Anda, klik **Tambah Layanan** → **GitHub**, lakukan otorisasi, lalu pilih repositori Anda.
2. Zeabur secara otomatis mendeteksi bahasa, framework, dan strategi build.
3. Atur environment variables di tab "Konfigurasi" jika diperlukan.
4. Pasang domain dan aplikasi Anda pun online.

**Bacaan yang direkomendasikan:** [Cara Kerja Deploy](/deploy/how-deploys-work) · [Integrasi GitHub](/deploy/methods/github-integration) · [Environment Variables](/deploy/config/environment-variables)

---

## 📧 Saya Butuh Layanan Kirim/Terima Email

Zeabur Email memungkinkan Anda mengirim dan menerima email menggunakan domain Anda sendiri.

1. Buka [Zeabur Email](/email) untuk membuat akun dan memverifikasi domain Anda.
2. Konfigurasikan record DNS (MX, SPF, DKIM).
3. Kirim dan terima email melalui SMTP atau REST API.

**Bacaan yang direkomendasikan:** [Layanan Email](/email) · [API Key Email](/email/email-api-keys) · [REST API Email](/email/email-rest-api)

---

## 🖥️ Saya Punya Server Sendiri

Gunakan mesin Anda sendiri (BYO Server) dan kelola deployment melalui antarmuka Zeabur.

1. [Daftarkan server](/server) di Dashboard.
2. Jalankan perintah instalasi yang disediakan Zeabur di server Anda.
3. Pilih server Anda saat membuat proyek baru.

**Bacaan yang direkomendasikan:** [Server](/server)

---

## 🔌 Saya Ingin Mengotomatiskan melalui API / CLI

Integrasikan Zeabur ke pipeline CI/CD Anda menggunakan API atau CLI.

- **CLI**: Jalankan `npx zeabur@latest deploy` untuk melakukan deploy dari terminal Anda.
- **GraphQL API**: Kendalikan proyek, layanan, dan deployment secara terprogram.
- **Upload API**: Unggah langsung aplikasi yang dikemas dalam format ZIP.

**Bacaan yang direkomendasikan:** [Deploy dengan CLI](/developer/cli) · [API Publik](/developer/public-api) · [API Key](/developer/api-keys)
