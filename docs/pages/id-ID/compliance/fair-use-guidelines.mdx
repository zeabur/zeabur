# Pedoman Penggunaan Wajar

Semua paket di Zeabur tunduk pada pedoman penggunaan wajar berikut. Pedoman ini dirancang untuk memastikan bahwa semua pelanggan mendapatkan akses yang adil dan setara ke layanan Zeabur.

## Contoh penggunaan wajar

- Situs statis seperti blog, dokumentasi, dan situs web pribadi.
- Database seperti MySQL, PostgreSQL, dan MongoDB.
- API backend untuk aplikasi seluler, aplikasi web, dan perangkat IoT.
- Object storage untuk gambar, video, dan file media lainnya.

## Bukan penggunaan wajar

- Layanan VPN dan Proxy.
- Penambangan mata uang kripto.
- Layanan scraping dan crawling.
- Aktivitas ilegal.
- Agregator torrent
- Bot dan skrip otomatis.

## Pedoman penggunaan

Kami berharap semua pengguna dapat menggunakan layanan kami secara wajar, dan kami berhak menangguhkan atau menghentikan akun mana pun yang melanggar pedoman ini.

- Untuk pengguna paket Serverless, karena Anda tidak terverifikasi melalui paket berbayar, jika kami mendeteksi bahwa penggunaan Anda tidak wajar, kami akan segera menghentikan layanan Anda, dan jika Anda terus melanggar pedoman, kami akan menangguhkan akun Anda secara permanen.
- Untuk pengguna paket Developer dan paket Team, kami akan memberi tahu Anda terlebih dahulu melalui email jika kami mendeteksi bahwa penggunaan Anda tidak wajar, dan akan ada masa tenggang 3 hari bagi Anda untuk menyesuaikan penggunaan.

## Penggunaan komersial

**Paket Serverless** dibatasi hanya untuk penggunaan non-komersial. Semua penggunaan komersial memerlukan paket Developer atau Team.

Penggunaan komersial didefinisikan sebagai setiap penggunaan yang ditujukan untuk tujuan komersial, termasuk namun tidak terbatas pada:

- Meminta pembayaran untuk akses ke layanan Anda.
- Mengiklankan atau mempromosikan produk atau layanan.
- Menerima pembayaran untuk pengembangan dan pemeliharaan layanan.
- Memiliki tujuan utama untuk pemasaran afiliasi.

> Donasi tidak dianggap sebagai penggunaan komersial.

Jika Anda tidak yakin apakah penggunaan Anda termasuk komersial, silakan [hubungi kami](mailto:contact@zeabur.com).

## Pelaporan penyalahgunaan

Zeabur bekerja sama dengan organisasi keamanan siber untuk memerangi kejahatan dan penggunaan berbahaya. Kami mendorong Anda untuk melaporkan setiap perilaku yang melanggar Pedoman Penggunaan Wajar. Jika Anda menemukan situs web atau aktivitas apa pun yang melanggar pedoman ini, segera laporkan kepada kami.

Silakan lihat [Pedoman Pelaporan Penyalahgunaan](/compliance/abuse-report) untuk mempelajari cara melaporkan penyalahgunaan.
