# Komunitas

Zeabur dibangun bersama orang-orang yang melakukan deploy, berbagi, dan menjalankan berbagai hal di atasnya. Berikut tempat Anda dapat bergabung.

- [Program Ambassador](/id-ID/community/ambassador-programme) — Bergabunglah dengan tim pendiri: paket Pro, kredit bulanan, akses lebih awal, dan jalur komunikasi langsung dengan tim
- [Kode Etik](/id-ID/community/code-of-conduct) — Norma yang kami pegang di seluruh ruang Zeabur
- [Zeabur Support](https://zeabur.com/support) — Kirim permintaan dukungan dan bagikan detail masalah kepada tim Zeabur
