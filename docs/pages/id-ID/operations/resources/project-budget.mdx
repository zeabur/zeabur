# Anggaran Proyek

Untuk menghindari biaya tinggi yang tidak terduga, Anda dapat mengonfigurasi anggaran untuk setiap proyek.

Anda akan menerima notifikasi ketika pemakaian mencapai 80% dari anggaran, dan layanan Anda akan ditangguhkan untuk menghindari biaya berlebih ketika anggaran tercapai.

## Cara Mengonfigurasi Anggaran

1. Buka pengaturan proyek dengan mengklik ikon roda gigi di pojok kiri atas dashboard proyek.

![Budget Entry](/manage/budget/budget-entry.png)

2. Di halaman anggaran, klik tombol "Perbarui Budget Bulanan" untuk mengatur anggaran proyek ini.

![Budget Page](/manage/budget/budget-page.png)

Anda dapat melihat biaya periode berjalan untuk proyek ini di halaman tersebut, sehingga Anda dapat menentukan anggaran yang sesuai untuk proyek.

## FAQ

### Bagaimana saya tahu jika proyek saya hampir mencapai anggaran?

Anda akan menerima notifikasi ketika pemakaian mencapai 80% dari anggaran, dan Anda juga dapat memeriksa pemakaian di pengaturan proyek.

### Apa yang terjadi ketika anggaran tercapai?

Layanan Anda di proyek ini akan ditangguhkan untuk menghindari biaya berlebih ketika anggaran tercapai.

### Apakah saya dapat mengubah anggaran setelah mengaturnya?

Ya, Anda dapat mengubah anggaran kapan saja. Anggaran baru akan langsung berlaku.

### Berapa anggaran minimum?

Anggaran minimum adalah $10.00.
