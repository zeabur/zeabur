# Email

Email adalah layanan API pengiriman email kelas enterprise dari Zeabur yang menyediakan solusi pengiriman email yang sederhana, andal, dan berperforma tinggi bagi developer.

## Fitur Inti

- **REST API yang Sederhana** - Integrasikan fungsi email hanya dengan beberapa baris kode
- **Pengiriman Instan & Terjadwal** - Kirim email seketika atau jadwalkan untuk nanti
- **Pengiriman Massal** - Kirim email dalam jumlah besar dengan manajemen antrean otomatis
- **Dukungan Lampiran** - Mendukung berbagai format lampiran email
- **Notifikasi Webhook** - Pembaruan status pengiriman secara real-time (terkirim, bounce, keluhan)
- **Manajemen Domain** - Mendukung domain pengirim kustom
- **Manajemen API Key** - Kontrol izin yang fleksibel (baca saja, kirim saja, akses penuh)

## Fitur Utama

### Keandalan Tinggi
Dibangun di atas AWS SES dengan jaminan uptime 99,9%, sehingga pengiriman email tetap stabil.

### Pemantauan Real-time
Terima pembaruan status email secara real-time melalui Webhook:
- Konfirmasi pengiriman
- Konfirmasi email diterima
- Notifikasi bounce
- Keluhan spam

### Keamanan
- Verifikasi tanda tangan HMAC-SHA256
- Isolasi izin API key
- Verifikasi DKIM/SPF domain
