# Verifikasi Akun Anda

Memverifikasi akun akan menautkan akun Zeabur Anda dengan forum komunitas, sehingga Anda dapat berdiskusi dan berinteraksi dengan komunitas dengan lebih mudah.

Anda juga mungkin mendapatkan sejumlah kredit sebagai hadiah atas aktivitas Anda di forum komunitas kami.

## Cara Melakukan Verifikasi

Kami menggunakan bot kami, **Zebra**, untuk membantu proses verifikasi.

### Langkah 1: Bergabung dengan Forum Komunitas Kami

Pertama-tama, Anda perlu [mengunjungi forum komunitas kami](https://zeabur.com/forum). Di sana Anda dapat berkomunikasi dengan staf kami dan pengguna lain, serta menyampaikan masukan dan masalah Anda.

### Langkah 2: Tautkan Akun Anda

Saat masuk ke forum komunitas kami, Anda akan melihat pesan sambutan dari Zebra. Anda akan menemukan [kanal verify](https://discord.com/channels/1060209568820494336/1095916895649153094) di dalam isi pesan tersebut.

![verify](/community/verify/verify.png)

Klik tombol verify, lalu Anda akan melihat halaman otorisasi. Klik tombol **Authorize** untuk menautkan akun Anda dengan situs web kami.

![authorize](/community/verify/authorize.png)

Setelah dialihkan ke situs web kami, Anda akan melihat pesan berhasil pada notifikasi, dan Anda dapat menutup situs web tersebut.

![verified](/community/verify/verified.png)

## Langkah Selanjutnya

Setelah verifikasi, Anda dapat berpartisipasi dalam diskusi di forum komunitas kami. Saat Anda meng-upgrade ke paket lain, **Zebra** akan secara otomatis memberi Anda peran khusus di forum komunitas kami. Dengan peran tersebut, Anda dapat bergabung ke kanal eksklusif.

![dev-plan](/community/verify/dev-plan.png)

Jika Anda menyukai format interaksi komunitas seperti ini, jangan ragu untuk membagikan pendapat Anda di [forum komunitas](https://zeabur.com/forum) kami.
