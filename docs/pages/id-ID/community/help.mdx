# Dapatkan Bantuan

Terkadang Anda mungkin mengalami masalah saat menggunakan Zeabur. Anda dapat menghubungi [Zeabur Support](https://zeabur.com/support) untuk mendapatkan bantuan dari tim Zeabur.

![Halaman Zeabur Support](/community/help/support-home.png)

## Cara Mendapatkan Bantuan

Buka [Zeabur Support](https://zeabur.com/support) dan kirimkan permintaan Anda dengan konteks yang cukup agar tim kami dapat menyelidikinya.

![Formulir pengiriman tiket](/community/help/support-submit-ticket.png)

### Format Permintaan

Mengikuti format ini membantu kami mengidentifikasi dan menyelesaikan masalah Anda dengan lebih cepat.

- Jelaskan masalah Anda secara singkat di judul permintaan.
- Jelaskan detail masalah, perilaku yang diharapkan, dan apa yang sudah Anda coba.
- Sertakan `projectID`, `serviceID`, atau `deploymentID` Anda jika masalah berkaitan dengan proyek atau layanan tertentu. Anda dapat menemukannya di URL dashboard Zeabur Anda.

### Dukungan Prioritas

Dukungan prioritas ditangani dengan Express pass. Paket berbayar mencakup sejumlah pass bulanan yang memungkinkan permintaan dukungan dari akun Anda masuk ke antrean prioritas:

| Paket | Express pass / bulan |
| ---- | ---------------------- |
| Developer | 2 |
| Pro | 5 |
| Team | 10 |

Express pass memengaruhi prioritas respons pertama: pass ini membantu permintaan Anda masuk ke antrean prioritas untuk balasan pertama dari tim kami, tetapi tidak menjamin waktu penyelesaian. Kami tetap berusaha membantu setiap pengguna menyelesaikan masalah secepat mungkin. Semakin banyak konteks yang Anda sertakan, seperti perilaku yang diharapkan, apa yang sudah Anda coba, ID terkait, log, dan tangkapan layar, semakin sedikit komunikasi bolak-balik yang diperlukan dan semakin cepat kami dapat membantu. Jika akun Anda tidak memiliki sisa Express pass, Anda tetap dapat mengirimkan permintaan dukungan, tetapi permintaan tersebut ditangani tanpa penempatan di antrean prioritas. Memverifikasi akun tidak dengan sendirinya memberikan dukungan prioritas; verifikasi membantu kami mengidentifikasi akun yang terkait dengan permintaan Anda lebih cepat. Ikuti [dokumentasi ini](./verify) untuk melanjutkan.

## Cara Lain Menghubungi Kami

Anda juga dapat menghubungi kami melalui email untuk dukungan atau pertanyaan:

- **Email:** [contact@zeabur.com](mailto:contact@zeabur.com)

Untuk waktu respons yang lebih cepat, kami merekomendasikan penggunaan [Zeabur Support](https://zeabur.com/support). Namun, jika Anda lebih suka berkomunikasi melalui email, jangan ragu untuk mengirimkan pesan kepada kami dan kami akan membalas secepat mungkin.
