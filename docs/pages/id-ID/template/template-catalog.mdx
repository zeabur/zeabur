# Katalog Template

Zeabur menyediakan katalog template yang lengkap sehingga Anda dapat dengan cepat melakukan deploy berbagai aplikasi dan layanan.

Kunjungi [Katalog Template Zeabur](https://zeabur.com/templates) untuk menjelajahi semua template yang tersedia.

## Cara Menggunakan Template

1. Temukan template yang Anda butuhkan di katalog template
2. Klik tombol "Deploy"
3. Ikuti petunjuk untuk menyelesaikan konfigurasi

Anda juga dapat membaca [Format Template](/template/template-format) untuk detail lebih lanjut tentang cara membuat template Anda sendiri.
