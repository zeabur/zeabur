# Direktori Root Kustom

Untuk beberapa repositori Git, seperti proyek yang berisi frontend dan backend sekaligus, Anda perlu menentukan direktori root proyek secara manual.

### Langkah 1: Deploy layanan

Ikuti panduan [Deploy layanan](/id-ID/get-started) untuk men-deploy aplikasi Anda

## Langkah 2: Ubah direktori root proyek

Klik layanan yang sudah di-deploy lalu masuk ke tab pengaturan, gulir ke bawah hingga kolom **Direktori Root**

![setting](/deploy/root-directory/setting.png)

Atur direktori root proyek Anda di sini.
