# Deploy Layanan dengan Ekstensi VS Code

Zeabur menyediakan beberapa ekstensi yang memungkinkan Anda men-deploy kode lokal dengan satu klik—tanpa perlu meninggalkan lingkungan pengembangan Anda.

Artikel ini akan memandu Anda men-deploy layanan menggunakan ekstensi VS Code Zeabur.

## Ekstensi VS Code / Cursor

Anda dapat menggunakan ekstensi Zeabur di editor Visual Studio Code maupun Cursor untuk men-deploy proyek lokal Anda langsung ke Zeabur.

### Instalasi

1. Buka VS Code atau Cursor.
2. Buka panel Extensions dan cari "Zeabur".
3. Klik "Install", atau langsung buka [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Zeabur.zeabur-vscode) untuk menginstalnya.

### Cara Menggunakan

1. Buka folder proyek yang ingin Anda deploy.
2. Klik ikon Zeabur di sidebar.
3. Klik "Deploy" — ini akan otomatis membuka jendela browser.
4. Pilih region deployment.
5. Proyek Anda akan di-deploy dalam beberapa menit.
