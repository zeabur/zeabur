# Tombol Deploy

Dengan tombol deploy kami, Anda dapat dengan mudah men-deploy layanan ke Zeabur hanya dengan satu klik. Tombol ini dapat disematkan di file markdown atau file HTML mana pun, dan dapat mengubah [template Zeabur](https://zeabur.com/templates) apa pun menjadi proyek yang siap di-deploy.

![button-demo](/deploy/button/button-demo.png)

## Apa itu Tombol Deploy

Tombol deploy adalah potongan kode HTML sederhana. Anda dapat menyalin potongan kode tersebut dan menempelkannya ke file markdown atau file HTML mana pun. Setiap tombol akan mengarahkan pengguna ke template yang diinginkan. Template tersebut dapat berupa satu layanan atau sekelompok layanan, sesuai yang ditentukan oleh pembuat template.

Tombol juga dapat diakhiri dengan kode referral milik pembuatnya. Setiap pengguna baru yang mendaftar dengan kode referral tersebut lalu meningkatkan ke paket berbayar akan memberikan kredit sebesar US$ 5 kepada pembuatnya.

## Menyalin Tombol

Karena tombol terhubung dengan sebuah template, hanya pembuat template yang dapat membuat tombol tersebut.

Untuk menyalin tombol, buka halaman akun di [Dashboard Zeabur](https://dash.zeabur.com/account), pilih tab **Template**, dan Anda akan melihat daftar template yang telah Anda buat.

![created-templates](/deploy/button/created-templates.png)

Pilih template yang diinginkan, lalu klik tombol bagikan. Sebuah modal akan muncul berisi kode tombol.

![popup](/deploy/button/popup.png)

Jika Anda memilih untuk mengaktifkan kode referral, kode tombol akan ditambahkan dengan kode referral Anda, yaitu username Anda di Zeabur.

## Kasus Penggunaan

Ini adalah cara terbaik untuk membagikan proyek hebat Anda yang di-deploy di Zeabur kepada dunia. Siapa pun dapat dengan mudah men-deploy proyek Anda dengan satu klik.

Misalnya, Anda dapat menempelkan tombol ini di tempat-tempat berikut:

- File README GitHub
- Blog
- Dokumentasi dan tutorial
- Profil media sosial

## Persyaratan

Anda perlu membuat template terlebih dahulu untuk mendapatkan tombol deploy. Anda dapat membuat template di [Dashboard Zeabur](https://dash.zeabur.com/create-template).

Seperti yang ditunjukkan pada gambar di bawah, Anda perlu mengisi nama template, deskripsi, dan memilih layanan yang ingin disertakan dalam template. Membuat template sangat mudah, semudah mengisi formulir.

![create-template](/deploy/button/create-template.png)

## Penghasilan

Seperti yang disebutkan di atas, Anda bisa mendapatkan kredit sebesar US$ 5 untuk setiap pengguna baru yang mendaftar dengan kode referral Anda dan meningkatkan ke paket berbayar. Anda dapat menggunakan kredit tersebut untuk membayar layanan Anda sendiri.

Anda dapat membaca penjelasan yang lebih lengkap di [dokumen referral](../community/referral) kami.
