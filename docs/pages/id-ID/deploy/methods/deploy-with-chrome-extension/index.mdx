# Ekstensi Chrome

Zeabur menyediakan beberapa ekstensi yang memungkinkan Anda men-deploy kode lokal dengan satu klik—tanpa perlu meninggalkan lingkungan pengembangan Anda.

Artikel ini akan memandu Anda men-deploy layanan menggunakan ekstensi Chrome Zeabur.

## Ekstensi Chrome

Ekstensi Chrome Zeabur memungkinkan Anda men-deploy kode langsung dari platform pembuat kode berbasis AI yang didukung, seperti Lovable, Bolt.new, atau v0.dev.

### Instalasi

Buka [Chrome Web Store](https://chromewebstore.google.com/detail/zeabur/mdcaillllhdkbocjldfclmkcmilkjpem) lalu klik "Add to Chrome".

### Cara Menggunakan

Saat Anda bekerja di platform AI yang didukung, tombol "Deploy with Zeabur" akan muncul di layar. Klik tombol tersebut untuk memulai proses deployment.
