# Deploy Proyek Gemini Canvas

Panduan ini menunjukkan cara mengubah proyek Gemini Canvas menjadi deployment Zeabur yang aktif hanya dengan beberapa klik menggunakan ekstensi Chrome Zeabur.

## Sebelum Memulai

- Instal [ekstensi Chrome Zeabur](https://chromewebstore.google.com/detail/zeabur/mdcaillllhdkbocjldfclmkcmilkjpem).
- Masuk ke Gemini dan Zeabur di browser yang sama agar Agent dapat menggunakan kembali sesi Anda.

## 1. Instal Ekstensi Chrome

Tambahkan ekstensi Chrome Zeabur dari Chrome Web Store dan sematkan (pin) agar mudah diakses.

![Install the Zeabur Chrome extension](/deploy/chrome-extension/gemini/gemini-step-1.png)

## 2. Buka Gemini Web dan Aktifkan Canvas

Di Gemini web, mulai percakapan dan aktifkan **Canvas** di pojok kanan bawah agar Anda dapat melihat pratinjau dan mengedit kode langsung di dalam Gemini.

![Enable Canvas inside Gemini](/deploy/chrome-extension/gemini/gemini-step-2.png)

## 3. Minta Gemini Membuat Aplikasi Web

Gunakan prompt Anda untuk meminta Gemini membuat aplikasi yang ingin Anda deploy. Tombol Zeabur akan berfungsi dengan proyek apa pun yang menghasilkan kode di pratinjau Canvas.

![Prompt Gemini to build your project](/deploy/chrome-extension/gemini/gemini-step-3.png)

## 4. Ubah Pratinjau ke `Code (original)`

Di panel pratinjau sebelah kanan, buka dropdown dan pilih **Code (original)** agar ekstensi dapat membaca kode sumber mentah yang dihasilkan Gemini.

![Switch the preview to Code view](/deploy/chrome-extension/gemini/gemini-step-4.png)

## 5. Temukan Tombol `Deploy with Zeabur`

Setelah pratinjau menampilkan kode, tombol **Deploy with Zeabur** berwarna ungu akan muncul di pojok kanan atas panel pratinjau Canvas.

![Deploy with Zeabur button in Canvas](/deploy/chrome-extension/gemini/gemini-step-5.png)

## 6. Lanjutkan ke Zeabur Agent

Klik tombol tersebut untuk beralih ke Zeabur Agent. Agent akan mengimpor bundel kode Gemini, memungkinkan Anda mengonfirmasi detail proyek, dan memandu Anda melalui langkah-langkah deployment yang tersisa hingga layanan aktif.

![Zeabur Agent import screen](/deploy/chrome-extension/gemini/gemini-step-6.png)
![Confirm deployment and go live](/deploy/chrome-extension/gemini/gemini-step-7.png)
