# Deploy Layanan dengan Ekstensi Raycast

Zeabur menyediakan beberapa ekstensi yang memungkinkan Anda men-deploy kode lokal dengan satu klik—tanpa perlu meninggalkan lingkungan pengembangan Anda.

Artikel ini akan memandu Anda men-deploy layanan menggunakan ekstensi Raycast Zeabur.

## Ekstensi Raycast

Dengan ekstensi Raycast Zeabur, Anda dapat dengan cepat men-deploy proyek, mencari dokumentasi, atau menjelajahi template.

### Instalasi

Buka Raycast Store dan cari ekstensi Zeabur. Anda juga dapat langsung membuka [Halaman Ekstensi Raycast Zeabur](https://www.raycast.com/ridemountainpig/zeabur) lalu klik "Install Extension".

### Cara Menggunakan

1. Setelah terinstal, buka Raycast dan ketik `Zeabur`.
2. Pilih perintah "Deploy Project".
3. Pilih folder proyek yang ingin Anda deploy lalu tekan `⌘ + Enter`.
4. Pilih region deployment. Proyek Anda akan di-deploy dalam beberapa menit.
