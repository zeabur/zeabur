# Dev Plan (Paket Developer)

Dev Plan adalah paket berbayar tingkat awal Zeabur yang dirancang untuk developer perorangan. Dengan harga **US$5/bulan** dan **uji coba gratis 14 hari**, paket ini membuka akses ke Zeabur AI, backup database otomatis, pembelian domain, dan layanan Zeabur Email — ideal untuk proyek produksi pribadi maupun proyek sampingan.

Untuk daftar fitur lengkap dan kuota terbaru, lihat [tabel perbandingan](/pricing).

## Kasus Penggunaan

- **Proyek sampingan pribadi** — Deploy situs web pribadi, blog, layanan API, dan lainnya.
- **Pengembangan & pengujian** — Environment yang memerlukan penyimpanan persisten (misalnya database) dan backup otomatis.
- **Layanan produksi kecil** — Layanan dengan lalu lintas rendah yang perlu berjalan 24/7.
- **Pengembangan template** — Buat dan kelola template Zeabur dengan [Tombol Deploy](/deploy/methods/deploy-button) untuk mempromosikan proyek Anda.

## Kapan Perlu Upgrade ke Pro

Jika Anda membutuhkan **log forwarding**, **kuota Email/Domain/API Key/Webhook yang lebih besar**, **ikon layanan kustom**, atau **dukungan prioritas**, [Pro Plan](/pricing/pro-plan) (US$19/bulan, uji coba gratis 14 hari) adalah langkah selanjutnya. Lihat halaman [Pro Plan](/pricing/pro-plan) untuk detailnya.

## Cara Berlangganan

Kunjungi [zeabur.com/pricing](https://zeabur.com/pricing) dan pilih Dev Plan, atau upgrade dari [halaman tagihan Dashboard](https://dash.zeabur.com/account/billing). Kartu kredit dan Alipay didukung — lihat [Metode Pembayaran](/subscription/payment-methods) untuk detailnya.
