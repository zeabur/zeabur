# Free Plan

Free Plan adalah paket gratis Zeabur yang dirancang untuk eksplorasi dan pembelajaran pribadi. Tidak perlu kartu kredit — cukup daftar dan mulai deploy.

Untuk daftar fitur lengkap dan batasan terbaru, lihat [tabel perbandingan](/pricing).

## Batasan

- **Tidur otomatis** — Layanan pada Free Plan akan otomatis tidur setelah tidak aktif selama beberapa waktu. Layanan akan aktif kembali saat ada permintaan masuk berikutnya, yang dapat menyebabkan latensi cold start selama beberapa detik.
- **Tanpa SLA** — Free Plan tidak mencakup Service Level Agreement.
- **Tanpa Zeabur Email** — Pengiriman email melalui [Zeabur Email](/email) tidak tersedia pada Free Plan.
- **Tanpa backup/impor database otomatis maupun log forwarding** — fitur operasional lanjutan ini tersedia mulai dari Dev Plan.

<Callout type="info">
Layanan pada Free Plan akan otomatis tidur saat idle untuk menghemat sumber daya. Jika Anda membutuhkan layanan yang berjalan terus-menerus, pertimbangkan untuk upgrade ke [Dev Plan](/pricing/dev-plan).
</Callout>

## Jalur Upgrade

Jika kebutuhan Anda melebihi Free Plan, Anda dapat upgrade ke paket berbayar:

- **[Dev Plan](/pricing/dev-plan)** — US$5/bulan (uji coba gratis 14 hari), ideal untuk developer perorangan dengan proyek produksi pribadi.
- **[Pro Plan](/pricing/pro-plan)** — US$19/bulan (uji coba gratis 14 hari), direkomendasikan untuk beban kerja produksi.
- **[Team Plan](/pricing/team-plan)** — US$79/bulan untuk 3 kursi (+US$24/kursi), dirancang untuk kolaborasi tim.
- **Enterprise** — Paket khusus dengan dukungan dan SLA khusus — [hubungi kami](https://zeabur.com/support) untuk detailnya.

Kunjungi [zeabur.com/pricing](https://zeabur.com/pricing) untuk membandingkan semua paket.
