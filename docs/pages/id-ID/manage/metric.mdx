# Pemakaian Layanan

Zeabur menerapkan model penagihan berbasis pemakaian, dan juga menyediakan grafik terperinci untuk menampilkan pemakaian layanan Anda.

Klik layanan Anda dan pilih tab **Metrik**, Anda akan melihat grafiknya.

### Pemakaian Memori

Menampilkan memori yang digunakan oleh layanan yang sedang berjalan.

![memory](/manage/metric/memory.png)

### Pemakaian CPU

Menampilkan CPU yang digunakan oleh layanan yang sedang berjalan.

![memory](/manage/metric/CPU.png)

### Pemakaian Jaringan

Menampilkan lalu lintas jaringan layanan yang sedang berjalan dari setiap region di Zeabur.

![network](/manage/metric/network.png)

### Pemakaian Disk

Segera hadir.
