# Zeabur Mesh

<Callout type="info">
Zeabur Mesh akan segera hadir. Nantikan kabar selanjutnya.
</Callout>

Zeabur Mesh adalah solusi komunikasi antarlayanan dan manajemen trafik yang memungkinkan konektivitas serta routing yang aman dan andal antara layanan-layanan Anda di Zeabur.

Dokumentasi lengkap akan tersedia setelah fitur ini diluncurkan. Jika Anda memiliki pertanyaan, hubungi [Zeabur Support](https://zeabur.com/support).
