# Harga

Zeabur menawarkan empat tingkat langganan ditambah opsi Enterprise yang dapat disesuaikan:

- **[Free Plan](/pricing/free-plan)** — US$0/bulan
- **[Dev Plan](/pricing/dev-plan)** — US$5/bulan (uji coba gratis 14 hari)
- **[Pro Plan](/pricing/pro-plan)** — US$19/bulan (uji coba gratis 14 hari, direkomendasikan untuk produksi)
- **[Team Plan](/pricing/team-plan)** — US$79/bulan untuk 3 kursi (+US$24/kursi)
- **Enterprise** — [hubungi kami](https://zeabur.com/support) untuk harga khusus
