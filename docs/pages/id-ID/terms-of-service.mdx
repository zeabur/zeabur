# Ketentuan Layanan

## Ringkasan

Untuk memudahkan Anda, kami merangkum poin-poin utama ketentuan layanan kami sebagai berikut:

1. kami akan mengirimkan email kepada Anda
2. kami dapat berkomunikasi dengan layanan lain atas nama Anda, seperti GitHub
3. Anda setuju untuk tidak meng-host konten ilegal apa pun di platform kami
4. kami telah memperoleh semua lisensi yang diperlukan atas seluruh kontribusi untuk komunitas open source kami yang dikirimkan ke repositori kode publik GitHub kami
5. Anda bertanggung jawab secara hukum atas konten dan layanan yang Anda deploy dan kelola di platform kami
6. kami akan mematuhi permintaan penghapusan terkait hak cipta
7. kami akan berupaya sebaik mungkin untuk memberi tahu Anda apabila ketentuan layanan kami berubah
8. layanan dan konten yang disediakan oleh Zeabur disediakan "sebagaimana adanya" tanpa jaminan apa pun

Jika Anda menggunakan platform Zeabur beserta layanannya, Anda menyetujui ketentuan ini.

Jika Anda memerlukan ketentuan lengkapnya, silakan baca konten berikut.
